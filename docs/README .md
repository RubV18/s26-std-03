# JSON-to-PPTX Disassembly Exporter

This directory contains the demonstration material for Ibrahim Hamade's
PowerPoint export module for the Futurdata Disassembly Wizard.

## Included files

- `source/example_air_fryer.json` — source Wizard JSON model.
- `output/Air_fryer_Philips_HD9252_output.pptx` — editable PowerPoint generated by the algorithm.
- `URS_TRACEABILITY.md` — mapping between the exporter and the relevant URS requirements.
- `FRIEND_CODE_COMPARISON.md` — comparison with the initial proof-of-concept implementation.

## Source-code location

The implementation is under:

```text
src/main/pptx_exporter.py
src/main/futurdata_pptx/
```

The shared desktop application can import the exporter with:

```python
from pptx_exporter import export_to_pptx
```

and invoke it with:

```python
generated_path = export_to_pptx(
    json_path,
    depth=depth_spec,
    include_bom=True,
)
```

## Dependencies

Install the module dependencies with:

```bash
python -m pip install -r src/main/requirements-pptx.txt
```

## Test

From the repository root:

```bash
python -m pytest src/tests/test_pptx_exporter.py
```

## Direct example

From the repository root:

```bash
python src/main/pptx_exporter.py \
  docs/pptx-exporter/source/example_air_fryer.json \
  docs/pptx-exporter/output/generated_example.pptx
```
